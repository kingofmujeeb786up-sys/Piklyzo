About Piklyzo

Piklyzo is a free browser-based image compressor, image resizer and form photo maker. It is designed for students, job applicants, creators and anyone who needs an image with a particular file size or dimension.

What can Piklyzo do?

  • Compress an image toward a target KB size.
  • Resize images by width and height.
  • Lock the original aspect ratio.
  • Add name and date stamps.
  • Add professional borders.
  • Add text watermarks.
  • Rotate and flip images.
  • Adjust brightness, contrast and saturation.
  • Convert to grayscale.
  • Export JPG, PNG or WebP.
  • Create a print-friendly PDF.
  • Share or copy the processed image.
  • Use quick form-photo presets.

Privacy

Image processing is performed inside the browser using the HTML Canvas API. This version does not intentionally upload your selected image to a Piklyzo server.

⚠️ Always check the exact photo dimensions and file-size requirements of the specific application or examination form before submitting.

How to Use Piklyzo

  1. Select or drag an image into Piklyzo.
  2. Choose a target KB size if required.
  3. Set width and height if required.
  4. Add name, date, border or watermark when needed.
  5. Use brightness, contrast and other adjustments if necessary.
  6. Press Process Image.
  7. Check the output statistics.
  8. Download, share, copy or print your image.
