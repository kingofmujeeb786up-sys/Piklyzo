Free image tools in Piklyzo

Piklyzo is a lightweight browser-based image utility for preparing photos and documents for everyday use.

Image Compressor

Reduce JPG and WebP file sizes toward a selected KB target without sending the image to a server.

Image Resizer

Set custom width and height in pixels and optionally preserve the original aspect ratio.

Form Photo Maker

Add a name, date and border to a photo before using it for an application or form.

Background Cleanup

Replace similar background colors with white, light blue or transparency using a lightweight color-threshold method.

Multiple Images

Select several images and process them with the same settings.

JPG, PNG and WebP

Frequently Asked Questions

Is Piklyzo free?

Yes. Piklyzo is designed as a free browser-based image utility and does not require an account.

Are my images uploaded?

The image editor processes selected images locally in your browser. The editing process does not require sending the selected image to a processing server.

Can Piklyzo make an exact KB file?

Piklyzo works toward the requested target size, but an exact file size cannot always be guaranteed. Image content, dimensions and encoding format affect the final file size.

Can I resize an image?

Yes. You can enter the desired width and height in pixels. The aspect-ratio option can keep the original proportions.

Is the background remover AI?

No. The built-in background cleanup is a lightweight color-threshold tool. It is not an AI subject segmentation system.

Can I make a PDF?

Yes. After processing an image, use Print / Save PDF. Your browser's print dialog can save the result as PDF.

Does Piklyzo work on phones?

Yes. The interface is responsive and is designed for modern mobile, tablet and desktop browsers.

Privacy

Piklyzo's image editor is designed for browser-side processing. Images selected for editing are read by the browser and processed locally. The image editor does not require users to upload their photos to a processing server. Users should still avoid processing sensitive documents on devices they do not trust.

Terms of Use

Piklyzo is provided as a general-purpose image utility. Users are responsible for checking the dimensions, file size, format and other requirements of the organization receiving their final image.
